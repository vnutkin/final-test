FlowerDelivery Intermediate
Техническое задание:
Сайт с доставкой цветов и получение заказов через Telegram бота



Цель проекта:
Создание веб-сайта для заказа доставки цветов с улучшенной интеграцией заказов через Telegram бота.



Общая информация о проекте:
Проект включает разработку веб-сайта для заказа цветов и улучшенного Telegram бота для приема заказов.



Область применения
Описание проблемы:
Необходимость удобного и быстрого способа заказа цветов через интернет и мессенджер.
В интернете на сайте размещается каталог цветов и сопутствующих товаров из разных магазинов.
Пользователи выбирают товары в корзину и оформляют заказ.
Магазины используют Telegram бот для получения заказа,
 уведомлений об изменении статуса заказа на сайт и передачи на сайт изменений статус заказа.


Пользователи системы:
Частные лица и компании.



Основные ограничения и допущения:
Пользователи должны иметь доступ к интернету и Telegram. Заказы принимаются только в рабочее время.



Функциональные требования
- Веб-сайт:
    - Регистрация и авторизация пользователей. Авторизация по телефону и паролю.
    - Просмотр каталога цветов.
    - Выбор цветов и добавление в корзину.
    - Оформление заказа. Форма для ввода адреса доставки и комментария.
    - Просмотр истории заказов в профиле пользователя.
    - Аккаунт администратора с входом по паролю admin. Администратор может изменить пароль. 
	Администратор может просматривать, добавлять, изменять, удалять товары в каталоге.
	Может изменять статус заказа (создан, оплачен, доставляется выполнен)
- Telegram бот:
    - по команде /start бот запрашивает пароль (используется пароль администратора) и запоминает IDtelegram для магазина.
	команда используется один раз при подключении магазина или смене контактного лица.	
    - Получение заказов с информацией о букетах и доставке. При завершении оформлении заказа на сайте заказ передается в магазин через бот по IDtelegram.
    - Уведомления о статусе заказа. При изменении статуса администратором уведомление об этом посылается в магазин через бот по IDtelegram.
    - Магазин также может посылать через этот бот уведомления об изменении статуса заказа на сайт. По команде /state проверяется IDtelegram айлв магазин посылается список активных заказов,
	пользователь может набрать номер заказа и задать его новое состояние нажатием соответствующей кнопки меню бота. Эта информация передается на сайт и регистрируется в базе данных.



Общая архитектура системы:
- Веб-приложение на Django.
- Серверная часть на Python с использованием Django.
- Описание подсистем и модулей:
- Модуль регистрации и авторизации пользователей и авторизации администратора. 
- Модуль каталога товаров.
- Модуль оформления заказа.
- Модуль управления заказами. Статус заказа может изменяться администратором или через  уведомления от бота. История всех заказов может просматриваться администратором.
	Пользователь может просматривать историю своих заказов. 



Модель данных:
- Таблица пользователей (IDuser, имя, email, телефон, пароль).
- Таблица товаров (IDitem, название, цена, изображение,IDshop).
- Таблица заказов (IDorder, IDuser, статус, адрес доставки, комментарий, дата).
- Таблица магазина (IDshop, IDtelegram, название)
- Таблица корзин (IBasket, IDorder, IDitem, количество )



Методы и стратегии тестирования:
- Юнит-тестирование.
- нагрузочное тестирование с locust
